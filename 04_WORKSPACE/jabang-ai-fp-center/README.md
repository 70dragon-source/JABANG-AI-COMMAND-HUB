# JABANG AI FP CENTER local workspace

## 실행

```bash
cd 04_WORKSPACE/jabang-ai-fp-center
python3 -m http.server 5173
```

브라우저에서 `http://localhost:5173` 접속.

## 이번 반영 범위

- JABANG AI FP CENTER 로고/CI 3종: 철벽방어, 보장타워, 병원·청구 네비
- 모든 페이지 공통 슬라이드덱 전체화면 버튼
- 모든 페이지 공통 영상 PT 전체화면 버튼 및 OFF 닫기
- 전 페이지 네온 카드 전역 스타일과 네온 검수 모드
- 보험사용설명서 엔진: 진단/상황별 청구서류 안내
- 보험회사별 청구양식 PDF 수작업 업로드 슬롯
- 병원네비게이션: 상급종합병원, 종합병원, 전문병원/클리닉, 응급실 경로
- V1 표준방어플랜 암 보장 3D 타워
- V3 실제 설계 담보만 반영한 암 보장 3D 타워
- 보험료 변경 전후 표: 해지/유지/신규가입/감액 및 절감액 표시
- 달러일시납 연금 환율 변화 그래프
- 계산 루트/디버그 숨김 정책 화면

## 남은 실제 데이터 연결 지점

현재 코드는 로컬 테스트 가능한 정적 엔진입니다. 엑셀/워드/PDF 원본이 저장소에 추가되면 `src/app.js`의 DATA 영역을 파서 출력으로 교체하면 됩니다.
