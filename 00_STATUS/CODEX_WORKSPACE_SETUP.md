# 💻 JABANG AI: Business Codex 워크스페이스 구축 가이드

자방선생님, 결제하신 "Business Codex"는 단순한 채팅방이 아니라 **"AI 개발팀 사령부"**입니다. 
지금까지 우리가 로컬 폴더와 GitHub를 왔다갔다하며 수동으로 통제하던 것을, 이 워크스페이스가 중앙에서 전부 자동으로 통제할 수 있습니다.

---

## 1. 정체 파악: 이게 도대체 무엇인가?

* **정체**: 프로그래머들을 위한 "멀티 에이전트 코디네이션" 플랫폼입니다.
* **비용 구조**: 월정액이 아니라 **종량제(크레딧)**입니다. 많이 일 시키면 깎이고, 안 시키면 안 깎이는 구조입니다. (결제된 165달러는 충전금 성격일 확률이 높습니다.)
* **특징**: "에이전트 A는 깃허브 리뷰해", "에이전트 B는 버그 찾아"처럼 여러 AI를 동시에 백그라운드에서 일하게 만들 수 있습니다.

---

## 2. 우리가 당장 구축해야 할 "1인 기업 커넥터" 셋팅

자방선생님은 올려주신 이미지 화면을 기준으로 딱 **1가지**만 당장 연결해두시면 됩니다.

### ⭐ 가장 중요: GitHub 저장소 연결
* 올려주신 이미지 최상단에 **"GitHub 계정이 연결되어 있지 않습니다. 지금 연결하세요"** 라는 배너가 떠 있습니다.
* 저 배너의 **[지금 연결하세요]** 글자를 클릭합니다.
* 우리가 코드 저장소로 쓰고 있는 `70dragon-source/JABANG-AI-COMMAND-HUB` 리포지토리를 연결합니다.
* **효과**: 이렇게 해두면, 제가(Antigravity) 코드를 짜서 GitHub에 올릴 때마다, 저 비싸고 똑똑한 Codex가 알아서 코드를 훑어보고 에러를 잡아서 자방선생님께 보안/코드 리뷰를 자동으로 바칩니다.

### 3. 부가 셋팅 (권한 열기)
* 왼쪽 [설정] > [일반/환경] 메뉴로 들어갑니다.
* **"Allow members to use Codex cloud"** (클라우드 코덱스 사용 허용) 기능이 켜져 있는지 확인합니다.

## 4. 이 요금제의 최종 활용법 (자방선생님의 포지션)

지금 자방선생님은 3개의 AI 무기를 손에 쥐셨습니다.
1. **로컬 (제3작업실/ANTI)**: 직접 파일 열고 폴더 지우고 코딩하는 손발 역할.
2. **GitHub**: 작업물 저장소 (창고).
3. **Business Codex (결제하신 것)**: 창고(GitHub)를 감시하면서, 로컬 AI(ANTI)가 짜놓은 코드가 완벽한지 24시간 검수하는 **"수석 감리사"** 역할.
