ANTI-GEN은 단순 실행파일이 아니다.

2. 자방선생님의 핵심 AI 일꾼

**ANTI-GEN 확인된 능력 (2026-05-09)**:
- React/TSX 파일 직접 수정 (Lovable 코인 없이 메인웹 수정 가능)
- Firebase MCP 직접 연동 (고객 데이터 실시간 저장/조회)
- GitHub MCP (수정 후 자동 push → Lovable 반영)
- Python 실행 (Ollama 연동, 분석 스크립트)
- 이미지 생성 (3D, UI 자산, 보고서 표지)
- 브라우저 자동화 (유튜브 감시, 데이터 수집)
- 다중 파일 동시 편집

**ANTI-GEN 확인된 실수 (2026-05-09)**:
